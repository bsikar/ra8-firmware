Detailed Description

UDS scaling factors for the V and H axes.

HUM Ch 67.2.22 p 3997. Each axis carries a 4-bit integer mantissa and a 12-bit fractional part. Set both halves of an axis to zero to disable scaling on that axis (UDS_SCALE = 0).
