Detailed Description

A declared or computed style: a presence mask plus property values.

style holds the bold / italic / underline VALUES as ra8_reflow_font_style_t bits (a set bit = "on"); align holds an ra8_reflow_align_t. A field is only meaningful when its ra8_css_set_t bit is present in set.
