Detailed Description

Centre-parametrisation of an SVG elliptical arc.

Result of priv_arc_center – the centre, the (radius-corrected) semi-axes, the x-axis rotation (as cos/sin), and the start angle + signed sweep, ready to sample. ok is false for a degenerate arc (zero radius or coincident endpoints), in which case the caller draws a straight line.
