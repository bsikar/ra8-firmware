================================================================================
Renesas R7KA8D2KFLCAC pinout summary
================================================================================

Package   : 289-pin BGA (12 mm x 12 mm, 0.65 mm pitch)
MCU group : RA8D2
Cores     : Arm Cortex-M85 @ 1 GHz primary + Arm Cortex-M33 @ 250 MHz
Memory    : 1 MB MRAM, 2 MB SRAM (ECC)

Source    : RA8D2 Hardware User's Manual R01UH1065EJ0130, section 1.5
            ("Pin Functions") -- committed under docs/reference/.

This file is a QUICK REFERENCE ONLY. Always cross-check against the
HUM before wiring anything up; package pin assignments change
across MCU variants and the canonical mapping lives in the manual.

--------------------------------------------------------------------------------
EK-RA8D2 on-board peripherals
--------------------------------------------------------------------------------

LEDs (from FSP board_leds.c):
    LED1 -- P6_00        (green)
    LED2 -- P3_03        (red)
    LED3 -- P10_07       (blue / status)

User buttons:
    SW1  -- P0_06        (active-low)
    SW2  -- P0_05        (active-low)
    RESET-- dedicated reset pin

J-Link OB debug (on-board, cannot be reassigned):
    SWDIO / SWCLK / TDO / TDI via the SEGGER OB target MCU

J-Link OB virtual COM port (USB CDC -- "VCOMM"):
    TXD8 -- PD_02       (PFS PSEL = k_ra8_psel_sci_async, 0x04)
    RXD8 -- PD_03       (PFS PSEL = k_ra8_psel_sci_async, 0x04)
    Channel: SCI8 (an SCI_B instance on RA8D2 -- the legacy
                    `libs/ra8_hal/src/ra8_sci.c` register layout
                    needs to be re-derived against HUM Ch 38
                    SCI_B registers before this UART will work.)
    Source: Renesas FSP `ek_ra8d2_ep` quickstart -- the board nets
            VCOMM_TXD_TO_EXT / VCOMM_RXD_FROM_EXT land here.

--------------------------------------------------------------------------------
Common peripheral pin candidates
--------------------------------------------------------------------------------

These are reasonable starting points for bring-up. Confirm each
against HUM section 20.4 ("Peripheral I/O Table") before trusting.

SCI0 UART (alternate debug console -- generic, NOT the J-Link OB CDC):
    TXD0 -- P1_01       (PFS PSEL = k_ra8_psel_sci_async, 0x04)
    RXD0 -- P1_02       (PFS PSEL = k_ra8_psel_sci_async, 0x04)

IIC0 I2C:
    SDA0 -- P4_00       (PFS PSEL = k_ra8_psel_iic, 0x07)
    SCL0 -- P4_01       (PFS PSEL = k_ra8_psel_iic, 0x07)

SPI0:
    RSPCK -- P1_02
    MOSI  -- P1_01   # LEGACY-OK: Renesas datasheet SPI pin label (COPI)
    MISO  -- P1_00   # LEGACY-OK: Renesas datasheet SPI pin label (CIPO)
    CS    -- P1_03

CANFD0:
    CTX0 -- P4_01       (PFS PSEL = k_ra8_psel_can, 0x10)
    CRX0 -- P4_02       (PFS PSEL = k_ra8_psel_can, 0x10)

USB FS (PHY pins are fixed by package):
    USB_DP -- USBHS1-DP  (not remappable)
    USB_DM -- USBHS1-DM  (not remappable)

Ethernet RGMII: 8 fixed pins on PortA / PortB, see HUM section 29.

GLCDC output (parallel RGB):
    LCD_CLK    -- PB_00
    LCD_TCON0  -- PB_01  (HSYNC)
    LCD_TCON1  -- PB_02  (VSYNC)
    LCD_TCON2  -- PB_03  (DE)
    LCD_DATA0..23 -- various Port B / C pins, see HUM section 39

xSPI0 (64 MiB external flash on EK):
    DQS, SCLK, CS, IO0..7 -- fixed on ports 4, 5, 7
