Detailed Description

Where one SHT_SYMTAB section and its string table live in the image.

Decoded once from a section header so the symbol scan below works from plain offsets instead of re-reading header fields inside its loop.

Invariant
entsize is non-zero, so count is always well defined.
See also
elf_symtab_decode Fills this in from a section header.
elf_symtab_find Consumes it.
