Detailed Description

Per-port RMAC configuration knobs.

Captured by ra8_rmac_init. All fields default to safe values when zero-initialized: 100-Mbit MII full-duplex, unicast-only filter, no IRQs enabled, no PFC, no EEE.

◆ eswclk_hz

uint32_t ra8_rmac_config_t::eswclk_hz

Live ESWCLK frequency in Hz (input to the MDC divider).

Used together with ::mdc_hz to program MPIC.PSMCS. Must equal the frequency actually delivered by ESWCKCR/ESWCKDIVCR after ra8_cgc_eswclk_init runs. A value of 0 falls back to a safe "PSMCS = max" code (slowest MDC).

◆ mdc_hz

uint32_t ra8_rmac_config_t::mdc_hz

Target MDC (PHY station-management clock) frequency in Hz.

IEEE 802.3 Clause 22 caps MDC at 2.5 MHz; most PHYs (including the GPY111 / PEF7071 on the EK-RA8D2) work happily at 1 MHz. A value of 0 falls back to k_ra8_rmac_mdc_default_hz (1 MHz).
