Detailed Description

Optional SD-card book source for the hybrid e-reader.

Brings up the Pmod2 microSD over SCI0 Simple-SPI -> ra8_sdmmc_spi -> ra8_fs (mirroring the pagecache / epub_open path), scans the FAT root for *.RBK files, and serves demand-paged byte-range reads out of the selected file. Each .RBK is the same compressed RBKC container the baked books use, so the rest of the app is source-agnostic. The opened book's file handle stays held (sh_sd_book_open) and sh_sd_book_read seeks + reads single compressed chunks on demand – the whole container is never resident. .EPB books use the same discipline (#230): sh_sd_open_epub holds the source file open and ra8_epub seeks + reads each ZIP entry on demand, so no whole-file buffer exists for EPUBs either. Mounting is best-effort: with no card (ra8_emulator run without --sd) ra8_sdmmc_spi_init() times out and the shelf stays baked-only.
