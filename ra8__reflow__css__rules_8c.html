Detailed Description

Content-CSS selector + @font-face rule parsing (#111).

The selector grammar (type / class / id / descendant compounds) and the @font-face descriptor parser for the v1 CSS subset documented in ra8_reflow_css.h. Parsed selectors and faces are interned into the caller-owned ra8_css_sheet_t name pool and rule / face tables. The top-level block dispatcher ra8_reflow_css_parse_one_block lives here because it drives the selector and @font-face parsers; it is invoked by the stylesheet scanner ra8_css_parse in a sibling translation unit. No MMIO, no heap.

Iterate prop:value; pairs in a declaration block (no braces).

Scans s[0..len) for semicolon-delimited declarations and invokes cb(ctx, prop, plen, val, vlen) for each pair that has a non-empty property and value after whitespace trimming.
