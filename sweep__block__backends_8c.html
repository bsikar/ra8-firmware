Detailed Description

The two in-tree #208 sweep backends (mem, rbkc-z9) + shared helpers (meter shim, wall clock, deterministic text filler).

mem serves the payload blob straight from resident memory (the harness floor); rbkc-z9 packs a genuine "RBKC" chunked .rabook container in memory with zlib level-9 streams (the same wrapping tools/epub_compile emits) and serves it through ra8_book_chunked_read, so every cache miss pays a real staged read plus a real tinfl inflate of exactly one chunk. Both implement the cbs_backend_t seam declared in sweep_block_internal.h and are published through cbs_priv_backends() in report order.

int cbs_rbkc_pack ( const uint8_t * blob,

static

Pack an RBKC container over blob with real zlib level-9 streams.

Compresses each block_bytes slice with mz_compress2 at MZ_BEST_COMPRESSION (the level tools/epub_compile uses), writing each stream straight into its final position and each payload-relative end offset straight into the chunk table, so the container is assembled in a single pass with no staging copy.

Parameters
[in]blobSource payload.
[in]blob_bytesPayload length in bytes (> 0).
[in]block_bytesChunk size in bytes (> 0).
[out]outContainer buffer (capacity out_cap).
[in]out_capCapacity of out in bytes.
[out]out_lenReceives the packed container length.
Returns
int 0 on success, 1 on a compression failure.
Precondition
out_cap covers header + table + count * mz_compressBound(block).
out and out_len are non-NULL.
Postcondition
On 0, out[0..*out_len) is a valid RBKC container over blob.
On 1, out contents are unspecified.
Note
Not thread-safe (uses no shared state, but the caller's buffers).

◆ cbs_rbkc_setup()

int cbs_rbkc_setup ( cbs_backend_t * be,
const uint8_t * blob,
uint32_t blob_bytes,
uint32_t block_bytes )
static

RBKC backend setup: pack a container at block_bytes and bind the demand-paged chunk reader over it.

Buffer budgets come from mz_compressBound(block_bytes) (the canonical worst-case stream size), so the staging capacity always covers the largest compressed chunk and the open-path validation in ra8_book_chunked_open cannot reject the container. The container "file" is read through a nested cbs_meter_t so raw compressed traffic is reported separately.

Parameters
[in,out]beBackend to bind.
[in]blobSource payload.
[in]blob_bytesPayload length in bytes (> 0).
[in]block_bytesChunk size in bytes (> 0).
Returns
int 0 on success, 1 on allocation / pack / open failure.
Precondition
be and blob are non-NULL.
No prior setup is live (teardown ran, or first use).
Postcondition
On 0, be->read serves the inflated flat blob via chunk reads.
On 1, all partial state is freed (safe to retry or exit).
Note
Not thread-safe (binds the static s_cbs_rbkc).
