Detailed Description

RA8 PDM-IF backend for the transport-neutral audio facade.

Tag
[Ring 4 / Service] {World: NS}

Binds one PDM-IF channel as a fixed-size mono PCM-S32LE source. Filter coefficients and board pin routing remain caller/BSP policy.
