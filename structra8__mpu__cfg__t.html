Detailed Description

Whole-MPU static configuration block.

regions points at a caller-owned array of region_count entries. mair0 / mair1 are written verbatim into MPU_MAIR0 / MPU_MAIR1.

Invariant
region_count <= MPU_TYPE.DREGION.
