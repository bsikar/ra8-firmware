Detailed Description

One sequence-channel descriptor slot (4 x 32-bit registers).

The MIPI DSI host stores 8 of these per sequence channel (descriptors 0..7) at the SQCH0DSC@ / SQCH1DSC@ blocks. Word A is the packet header, B selects payload source, C carries auxiliary action codes, D is the lower address of an external payload buffer.
