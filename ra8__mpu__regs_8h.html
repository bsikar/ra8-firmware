inlinestatic

Accessor for the architectural Cortex-M85 MPU register block.

Returns
Pointer to the live MPU registers.
Precondition
Called from privileged mode (or RA8_OFF_TARGET).
Postcondition
Returned pointer is non-null and word-aligned.
Note
Not thread-safe.
