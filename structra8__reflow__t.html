Detailed Description

Reflow / pagination engine state.

Allocated by the caller (typically as a static in the ereader app) and bound via ra8_reflow_init(). Treat all fields as read-only; mutate only through the ra8_reflow_* API.

Invariant
in_use == 1 while initialized; cleared by ra8_reflow_close().
See also
ra8_reflow_init()
ra8_reflow_close()
