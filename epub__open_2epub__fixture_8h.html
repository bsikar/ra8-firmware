Detailed Description

Baked known-good EPUB3 fixture (tests/fuzz/corpus/fuzz_ra8_epub/seed_two_chapters.epub).

A minimal valid EPUB (mimetype + container.xml + content.opf with a 2-chapter spine + two XHTML chapters), byte-identical to the fuzzer corpus seed. Baked as a C array so the HIL opens it through the real ra8_epub parse path (miniz ZIP inflate via the ra8_epub_miniz_alloc static arena). Pure ASCII.
