Detailed Description

Caller-owned private state for an OSPI NOR block device.

Zero-initialise and pass to ra8_io_blockdev_xspi_init, which fills it and binds it into a ra8_io_blockdev_t. Treat the fields as private. The state must out-live every call made through the device. The window described by base_off and block_count must lie within the physical flash and be whole-sector aligned (see ra8_io_blockdev_xspi_init).

Invariant
base_off is a multiple of 4096 (one erase sector).
block_count is a non-zero multiple of 8 (whole sectors).
instance is a valid xSPI instance (< 2).
