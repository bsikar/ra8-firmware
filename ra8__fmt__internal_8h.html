Detailed Description

Cross-TU declarations shared inside the ra8_fmt tool.

The tool is one module split across several translation units (CLI, shared utilities, and one TU per format family). These are the helpers a format's verbs share across those TUs; nothing here is public API – consumers use the ra8_fmt_desc_t seam in ra8_fmt.h.

Read a source image's pixel dimensions from its container header.

Sizing the producer work arena needs the geometry up front, so the probe reads the PNG IHDR directly and defers to the firmware JPEG header scanner otherwise. This is header parsing only – no pixel is decoded, so it is cheap enough to run before every encode.

Parameters

[out]out_wReceives the image width, pixels.
[out]out_hReceives the image height, pixels.
Returns
ra8_err_t Error code.
Return values
k_ra8_okDimensions read into the outputs.
k_ra8_err_null_ptrA required pointer is NULL.
k_ra8_err_invalid_sizeA dimension is zero or above the format cap.
otherPropagated from the JPEG header scanner.
Precondition
src holds a PNG or JPEG source.
out_w and out_h are writable.
Postcondition
On success both outputs are in [1, k_ra8_jof_max_dim].
On any error neither output is relied upon.

Decode every tile of an atlas and reassemble the full raster.

Places each tile at (tile_x * tile_w, tile_y * tile_h) using the tile's own edge-clamped dimensions, which is precisely the placement rule a correct consumer must follow. Reassembling here and comparing against the untiled reference is what separates a producer defect from a consumer defect.

size_t ra8_fmt_jof_sink_cap ( size_t src_len)
nodiscard

Compute a safe memory-sink capacity for an atlas built from a source.

A lossless DEFLATE atlas of a decoded image can exceed the encoded source by a wide margin (a small JPEG decodes to a large raster), so the sink is sized from a generous multiple of the source plus a fixed floor – this is a host tool, so over-allocating is free.

Parameters
[in]src_lenEncoded source length in bytes.
Returns
Sink capacity in bytes.
Return values
>=src_lenAlways at least the source length.
Precondition
src_len is a real file length (below k_ra8_fmt_max_input).
The caller frees the resulting allocation.
Postcondition
No state is mutated.
The result is non-zero.
Note
Pure; thread-safe.
