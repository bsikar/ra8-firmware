Detailed Description

Filesystem-format registry: probe a volume + report capabilities.

Tag
[Ring 4 / PAL] {World: NS}

Holds pointers to registered ra8_io_fsfmt_t descriptors and probes them in order against a block device's boot sector. FAT and exFAT are built-ins whose probes read block 0 directly (no ra8_fs internals); foreign formats register through ra8_io_fsfmt_register. Every check is a single condition, so no MC/DC vectors are due.
