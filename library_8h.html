Detailed Description

@generated tools/bake_library.py – do not edit by hand.

Baked full .rabook blobs + pre-decoded cover thumbnails (generated).

Each entry is the chunked RBKC container (ra8_book_open inflates it on demand) plus a gray8 cover thumbnail the shelf blits without any boot-time inflation. Regenerate with tools/bake_library.py (the thumbnail bytes are architecture-dependent to regenerate; see scripts/builders/books.sh – re-pin the fb golden when re-baking).
