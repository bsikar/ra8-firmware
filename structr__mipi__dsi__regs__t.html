Detailed Description

MIPI DSI host register block (full layout).

Every documented register in HUM Ch 65 has a named field. The intervening reserved arrays hold the exact byte count to keep the named offsets aligned with the FSP R_MIPI_DSI_Type layout. Total struct size matches the FSP Size = 2176 (0x880) declaration so a static_assert below catches any accidental drift.

Invariant
sizeof(r_mipi_dsi_regs_t) == k_ra8_mipi_dsi_window_bytes
