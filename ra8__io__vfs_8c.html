Detailed Description

VFS mount table + "name:/path" router over ra8_fs.

Tag
[Ring 4 / PAL] {World: NS}

A fixed table maps short names to ra8_fs_mount_t volumes. Path operations split a "name:/sub" string, look the mount up, and delegate the sub path to the matching ra8_fs operation. All string scans are bounded and use only single-condition guards (no compound decisions, so no MC/DC vectors are due).
