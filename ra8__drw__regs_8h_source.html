543/* =============================================================================
544 * Display list encoding
545 *
546 * A display list is a stream of 32-bit words the DRW's display-list reader
547 * (DLR) fetches from RAM after DLISTSTART is written (HUM Ch 62.6 "Display
548 * List Mode" p 3724). The HUM documents the concept but not the word layout;
549 * the layout below is the one the DLR consumes, decoded from the vendored TES
550 * D/AVE 2D reference (its software DLR model d2_executedlist_intern and
551 * register map: register index == byte offset / 4) and bench-verified on an
552 * EK-RA8D2 (issue #247).
553 *
554 * Each entry is a TAG word followed by one value word per register it writes.
555 * The tag packs up to four register indices, one per byte. The first byte
556 * position >= 1 whose bit 7 is set marks the entry's boundary: byte 1 -> one
557 * register, byte 2 -> two, byte 3 -> three, none set -> four. A word whose low
558 * byte is 0xFF is an end-of-list marker with an argument in byte 1 (2 = wait
559 * for the pipeline and cache then continue; 3 = terminate).
560 * =============================================================================
561 */
