# USB identifiers used by examples

USB device examples in this tree use VID `0x1209` from the pid.codes
free-for-experiments range and an application-specific PID. These identifiers
are for development and bench testing only; they do not identify a registered
product. An example that states a PID explicitly owns that assignment.

Connector selection, role switching, VBUS control, and peripheral pin routing
remain documented in each application's README because those details vary by
example.
