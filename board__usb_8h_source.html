417/* =============================================================================
418 * Self-loop role routing (Config A vs Config B).
419 *
420 * The two on-chip controllers can run the self-loop in either polarity: HS
421 * host + FS device ("Config A", the default) or FS host + HS device ("Config
422 * B", dfu_selftest_fs_host). On silicon each controller's role is selected by
423 * the firmware itself through SYSCFG: DCFM=1 declares controller (host) mode
424 * (HUM Ch 36.2.1 / 37.2.1), DPRPU=1 declares the device-role D+ pull-up. The
425 * models mirror that: a DCFM=1 write to the USBFS window, or a DPRPU=1 write
426 * to the USBHS window, swaps the window<->model binding so the single host
427 * model serves the window the firmware drives as host and the single device
428 * model serves the other -- no per-app configuration, the register writes
429 * decide, exactly as the silicon does.
430 * =============================================================================
431 */
