Detailed Description

Opened EPUB book.

Populated by ra8_epub_open(). The struct is exposed (not behind a pointer) so callers can statically allocate it. Treat all fields as read-only; modify only via the ra8_epub_* API.

Invariant
in_use == 1 while a book is open; cleared by ra8_epub_close().
See also
ra8_epub_open()
ra8_epub_close()
