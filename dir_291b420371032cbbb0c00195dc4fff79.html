Detailed Description

Proves the ra8_io fabric's swappable-backend promise (#155, #156): the same VFS API that ra8_io_demo runs over a RAM disk, running over a microSD card by swapping only the block device. Everything above ra8_io_blockdev_sdspi_init is identical – the ra8_fs bridge, the format and mount, the VFS mount, mkdir, a write, a read-back and a byte-compare against a deterministic payload. Every return value is checked and the first failing step parks the CPU.

The SD bring-up itself – the Pmod2 / SCI0 Simple-SPI transport adapter and card init – is reused verbatim from fs_format_mount rather than reimplemented.

This app erases the card. It reformats the volume. Use a disposable microSD.

An unseated or missing card is the first thing to rule out when it fails.
