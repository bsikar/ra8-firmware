Detailed Description

One OV5640 camera sensor on the SCCB (I2C) bus.

The OV5640 addresses its register file with a 16-bit big-endian pointer: each transfer writes the pointer high byte then low byte, then either a data byte (register write) or, after a repeated-START, one read byte (register read). The model answers the chip-ID registers so the firmware's VERIFY-FIRST probe reads 0x5640; every other register reads 0 and config writes are accepted.
