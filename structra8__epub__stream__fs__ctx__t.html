Detailed Description

Backing state for a streamed ra8_fs EPUB open (#151).

Holds the open source-file handle for a book opened via ra8_epub_open_streamed_fs(). The streamed path keeps the file open for the book's whole lifetime and seeks+reads each ZIP entry on demand – so this context, and the file it owns, must out-live the book. Release both with ra8_epub_close_streamed_fs().

Invariant
file != NULL between a successful open and the matching close.
