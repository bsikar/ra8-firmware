Detailed Description

Tiled-atlas source adapter for the tap-to-zoom viewer (#478).

Implements ra8_zoom_tiles.h: pixel rectangle -> covering tiles -> per-tile acquire, copy the overlap, release. The acquire/release pair brackets exactly one copy, so at most one cell is ever pinned and the resident set is whatever the cache holds rather than whatever the rectangle spans – which is what makes "only visible tiles are resident" a property of the code rather than a hope.

The whole TU is guarded on ra8_tile_cache.h being reachable, the same pattern ra8_comic_tiles.c uses.
