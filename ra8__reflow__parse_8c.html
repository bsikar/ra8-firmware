Detailed Description

HTML-subset parser entry point for ra8_reflow.

The actual scan lives in ra8_reflow_tokenize.c (a no-heap streaming tokenizer). This C TU is the public entry point: ra8_reflow_layout_chapter() dispatches into ra8_reflow_parse_xhtml(), which validates arguments, resets the pools, and forwards to priv_reflow_xml_walk().

Keeping this entry point small lets clang-tidy's readability-function-size rule act on a single small function.

Parse the XHTML buffer into the engine's token stream.

Internal helper used by ra8_reflow_layout_chapter(). Implemented by the no-heap streaming tokenizer in ra8_reflow_tokenize.c. Declared here so ra8_reflow_layout.c can call it without a forward declaration.
