Detailed Description

One recorded page/chapter failure: what failed, and with what status.

Captured by the run so an end-of-run summary can name every lost page long after its one-line diagnostic has scrolled past. The raw ra8_err_t is kept (not a prose string) so the caller renders a human-readable reason at print time via mdl_fetch_reason.

Invariant
status == 0 when no HTTP status was observed (transport error or a robots refusal before any request).
