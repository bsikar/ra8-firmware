Detailed Description

Baked minimal EPUB3 with a real PNG cover (cover-image manifest item).

A 96x144 four-band RGB PNG cover wrapped in a one-chapter EPUB3, byte-identical run to run. The ereader_cover gate opens it in memory (ra8_epub_open), extracts the cover (ra8_epub_get_cover_image), and decode+scale+blits it (ra8_img_decode_blit); the framebuffer hash in hil.conf pins the result. Generated by make_cover_fixture.py. Pure ASCII.
