Detailed Description

PNG chunk layer for the streaming decoder: prologue, palette tables, ancillary skipping and the post-IDAT walk (#231).

The byte-source primitives and every chunk-structure concern of the bounded-RAM PNG decoder live here; the pixel layer (inflate + unfilter + translate) drives them from ra8_jof_png.c through the prototypes in ra8_jof_png_internal.h. All structural anomalies fail closed: this parser feeds on untrusted EPUB content. Spec citations reference the W3C PNG specification (second edition), abbreviated PNG sec N.
