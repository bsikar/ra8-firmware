Detailed Description

Bounded-buffer sink state for a page fetch.

Handed to mdl_net_curl_buf_write as libcurl's write-data. The write callback appends into buf until cap is reached, then latches overflow and aborts the transfer.

Invariant
len <= cap whenever overflow is false.
