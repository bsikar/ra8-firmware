Detailed Description

One ::ra8_vmem instance sized for a swept block size + its storage.

Frame storage, metadata, and buckets are heap-carved per leg so every leg starts cold; the vsource-level cbs_meter_t counts storage commands (== misses) and delivered bytes.

Invariant
frames == k_cbs_cache_bytes / frame_bytes (>= 1).
