Detailed Description

Out-parameter struct returned by ra8_epub_xml_parse_container().

Carries the rootfile path lifted out of META-INF/container.xml. The OPF path is always non-empty on success; the caller feeds it to the second pass, ra8_epub_xml_parse_opf().

Invariant
opf_path is NUL-terminated whenever the parse returned k_ra8_ok.
opf_path is never longer than k_ra8_epub_max_path_len - 1.
Example:
ra8_epub_container_result_t res = {};
if (ra8_epub_xml_parse_container(buf, len, &res) == k_ra8_ok) {
// res.opf_path names the OPF document inside the archive
}
