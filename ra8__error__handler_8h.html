Detailed Description

Centralised fatal-error sink.

internal_ra8_fatal_error() is the single entry point for "stop running and alert the developer". Every RA8_ASSERT and every RA8_ERROR_CHECK that fails eventually lands here.

The default behaviour is:

  1. Mask all interrupts.
  2. Emit a log line on the default backend.
  3. If a debugger is attached, __BKPT(0).
  4. Loop in __WFI forever.

The loop is deliberate: we do not want to reset silently because that erases the state the developer needs to diagnose the fault. Field deployments can override internal_ra8_fatal_error() with a weak symbol to add a watchdog reset.
