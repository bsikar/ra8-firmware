Detailed Description

Caller-owned zero-heap scratch for one ra8_rar5_decompress call.

Every field is decoder-private working storage, reset at the start of each call; a caller only supplies the memory (typically embedded in an ra8_comic_t). Holds the five Huffman decode tables, the streaming bit-reader window and cursor, the recent-distance ring, and the pending filter list plus the delta reorder buffer.

Invariant
filter_count <= k_ra8_rar5_max_filters.
Contents are meaningful only between the start and end of one ra8_rar5_decompress call.
