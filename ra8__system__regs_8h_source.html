279/* =============================================================================
280 * Direct register accessors
281 * =============================================================================
282 *
283 * Rather than define a single bloated R_SYSTEM struct (3456 bytes of
284 * bitfields), we expose a tiny set of typed accessors that each return
285 * a pointer to one register. The caller reads / writes whole 8/16/32-bit
286 * values and masks bits using the named constants above. This is
287 * exactly how the rx72n project handled its SYSTEM block and keeps the
288 * header under 200 lines.
289 */
