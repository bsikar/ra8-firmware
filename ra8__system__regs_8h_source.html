275/* =============================================================================
276 * Direct register accessors
277 * =============================================================================
278 *
279 * Rather than define a single bloated R_SYSTEM struct (3456 bytes of
280 * bitfields), we expose a tiny set of typed accessors that each return
281 * a pointer to one register. The caller reads / writes whole 8/16/32-bit
282 * values and masks bits using the named constants above. This is
283 * exactly how the rx72n project handled its SYSTEM block and keeps the
284 * header under 200 lines.
285 */
