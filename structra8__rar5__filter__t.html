Detailed Description

One pending RAR5 data filter recorded during decode, applied after.

The RAR5 token stream can insert a filter that post-processes an output range (executables/audio compress better delta/branch-transformed). For comic JPEG/PNG pages filters are effectively never emitted, but a conformant decoder records and replays them in order once decoding ends.

Invariant
type <= 3 (delta / e8 / e8e9 / arm).
