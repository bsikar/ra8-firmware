Detailed Description

Configuration for a single scan group.

Each group enumerates the physical channels it scans plus the trigger source and priority class. num_channels must be in 1..k_ra8_adc_scan_group_max_channels.

The driver assigns one ADCHCR slot per channel listed (slot index == channel index, matching the read-channel convention used by the legacy polling API).
