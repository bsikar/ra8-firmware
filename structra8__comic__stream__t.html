Detailed Description

Stable seek+read descriptor bound to the CBZ backend's miniz reader.

Held inside ra8_comic_t so miniz's I/O-opaque pointer has a lifetime address; the CBR backend leaves it unused.

Invariant
read != NULL once ra8_comic_open has bound a CBZ.
