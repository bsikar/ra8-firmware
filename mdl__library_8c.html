◆ mdl_library_for_each()

ra8_err_t mdl_library_for_each ( const char * out_dir,
mdl_library_fn cb,
void * ctx )

Visit every tracked series under a library root.

Scans the immediate subdirectories of out_dir and, for each that contains a .mdl_state file, invokes cb with that series' directory and state-file paths. Enumeration stops early if cb returns anything other than k_ra8_ok. A missing out_dir is not an error – an empty library visits nothing.

Parameters
[in]out_dirLibrary root directory (never NULL).
[in]cbPer-series callback (never NULL).
[in,out]ctxOpaque context forwarded to cb, or NULL.
Returns
An ra8_err_t result.
Return values
k_ra8_okEvery tracked series was visited (or none exist).
k_ra8_err_invalid_argout_dir or cb was NULL.
otherThe code cb returned to stop the walk.
Precondition
out_dir and cb are non-NULL.
cb tolerates being called zero times (an empty library).
Postcondition
Directory entries are visited at most once each.
No directory is modified by the walk itself.
Note
Not thread-safe.
Since
0.1.0

◆ mdl_library_remove_tree()

ra8_err_t mdl_library_remove_tree ( const char * dir)

Delete a directory tree (a whole series) depth-first.

Removes dir and everything under it, files before their parent directories, so a tracked series (its pages, archives and state file) is gone in one call. Symlinks are removed as links, never followed, so a series directory cannot be used to delete outside itself.

Parameters
[in]dirDirectory tree to remove (never NULL).
Returns
An ra8_err_t result.
Return values
k_ra8_okThe tree was removed (or already absent).
k_ra8_err_invalid_argdir was NULL or empty.
k_ra8_failA file or directory could not be removed.
Precondition
dir is non-NULL and NUL-terminated.
The caller has resolved dir to the intended series directory.
Postcondition
On k_ra8_ok no path under dir remains.
Nothing outside dir is touched.
Note
Not thread-safe.

0.1.0
