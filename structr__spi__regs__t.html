Detailed Description

SPI_B register-window mirror (matches FSP R_SPI_B0_Type, 0x70 bytes).

Every register is 32-bit. The layout is taken verbatim from R7KA8D2KF_core0.h, with the FSP nested anonymous unions / bit structs flattened to plain uint32_t words. Bit-level access goes through the masks/positions enums in this header instead of named bit-fields so layout is debugger-stable.
