Detailed Description

All ra8_longstrip state + owned buffers for one open JOF strip.

The strip's atlas bytes are slurped into atlas (the memstore pread reads from it); the tile cache decodes DEFLATE bands on miss into cells. The strip is paginated: each viewer "page" is one viewport_h -tall window scrolled down the canvas.

Invariant
All pointers are NULL unless the document is k_vfmt_jof.

0.1.0
