◆ mdl_state_load()

ra8_err_t mdl_state_load ( const char * path,
mdl_state_t * st )

Load a series' state from disk.

Parses the v1 format (see the file header). A file that is absent is NOT an error – st is initialised empty and k_ra8_ok is returned, so the first run of a new series just starts fresh. A file that exists but does not parse (wrong version, malformed record, over-capacity) leaves st initialised empty and returns k_ra8_err_invalid_state, giving the caller a clear rebuild path rather than a crash or a silent full refetch.

Parameters
[in]pathState file path (never NULL).
[out]stState to fill; always left in a valid (possibly empty) form.
Returns
An ra8_err_t result.
Return values
k_ra8_okLoaded, or the file was absent (empty state).
k_ra8_err_invalid_argpath or st was NULL.
k_ra8_err_invalid_stateThe file exists but is corrupt/unsupported.
Precondition
path and st are non-NULL.
The caller treats k_ra8_err_invalid_state as "rebuild", not "abort".
Postcondition
st is always a valid state object on return (empty on any error).
On k_ra8_err_invalid_state a diagnostic naming path is printed.
Note
Not thread-safe.

◆ mdl_state_save()

ra8_err_t mdl_state_save ( const char * path,
const mdl_state_t * st )

Persist a series' state atomically.

Writes to <path>.tmp and then renames it over path, so a process killed mid-write can never leave a half-written (thus corrupt) state file – the old file survives intact until the complete new one replaces it in one step. This is what makes per-page checkpointing safe: the fetch loop can save after every page without risking the record it is protecting.

Parameters
[in]pathState file path (never NULL).
[in]stState to write (never NULL).
Returns
An ra8_err_t result.
Return values
k_ra8_okWritten and renamed into place.
k_ra8_err_invalid_argpath or st was NULL.
k_ra8_failThe temp file could not be written or renamed.
Precondition
path and st are non-NULL.
path's directory exists and is writable.
Postcondition
On k_ra8_ok path holds the complete serialised st.
On failure path is left as it was (the temp file is removed).
Note
Not thread-safe.
See also
mdl_state_load

0.1.0
