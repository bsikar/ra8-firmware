Detailed Description

Raw register snapshot returned by ra8_reset_get_raw.

cppcheck cannot see tests/ so it flags every member as unused; each field is read by the test suite in tests/test_ra8_reset.c and by any caller that wants to see every latched flag at once.

Invariant
rstsr0 and rstsr2 are 8-bit reads; the upper bits of the wider integer storage are always zero.
