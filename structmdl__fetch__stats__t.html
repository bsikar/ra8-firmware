Detailed Description

Tallies a fetch run reports back (all zero-initialised by the run).

These are what the host tests assert on: pages_fetched counts real network transfers, pages_reused counts dedup/resume hits served from disk, so "second run fetches only the new ones" is a direct numeric check.
