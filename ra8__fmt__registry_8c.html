Detailed Description

The format registry: one descriptor row per first-party container.

The single source of truth the CLI drives dispatch and its usage text from. Adding a format is one row here plus its verb implementations – no CLI change, which is the Open/Closed property the ra8_fmt_desc_t seam buys.

Scope

These are the first-party content container formats. Deliberately excluded are the firmware and security artifacts (Root-of-Trust image trailers, NPU/vela blobs, device-identity records): they are not content, are not produced from a user file, and dumping them from a general-purpose media tool would invite treating signed artifacts as convertible data.
