Detailed Description

Tile-cache paging of JOF atlases + a real reflow img loader (#231).

Implements ::ra8_epub_tile_binder (pages JOF tile atlases through ::ra8_tile_cache, decode-on-demand keyed by image_id + tile, bounded RAM) and ra8_epub_reflow_img_load (resolves an <img src> href to encoded bytes in a caller-owned bounded scratch). Atlas sources are either stored archive entries (windowed with ra8_epub_entry_pread) or external pread seams (SDRAM/SD stores filled by the import path in ra8_epub_img_import.c). Tile decode itself is ra8_jof_read_tile() – one bounded read plus one bounded inflate per miss.

Guarded on __has_include: the pure ra8_epub core (and epub-only apps that never pull in ra8_mem/ra8_jof) still link with this TU empty.
