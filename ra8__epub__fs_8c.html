Detailed Description

ra8_fs -> ra8_epub bridge implementation (Phase 4.2 file adapter).

Tag
[Ring 4 / EPUB] {World: S}

Opens a .epub living on a mounted ra8_fs volume by streaming it (#151/#230): the file stays open for the book's lifetime and every ZIP read seeks+reads on demand, so no whole-file buffer ever exists. Guarded on __has_include("ra8_fs.h") so the pure ra8_epub core still links into apps/hosts that do not pull in ra8_fs (this TU is then empty – only the in-memory ra8_epub_open() path is used).
