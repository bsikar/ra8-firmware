Detailed Description

Configuration descriptor for ra8_mipi_csi_init.

Fields cover everything programmable in MCT0 / MCT2 / EMCT / EPCT

  • the receive data-type filter masks. Per-VC, per-DL, PM, and short-packet IRQ enables can be set via ra8_mipi_csi_init (the matching arrays below) or applied later through the per-group setters. frrclk and frrskw are vclk/hsclk-derived rate- adjust values described in HUM Ch 66.3.3 "MCT2 : Module Control Register 2" p 3937; the caller is expected to compute them.
