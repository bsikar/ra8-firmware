Detailed Description

Opened longstrip-strip scroll state (caller-owned; treat as private).

Filled by ra8_longstrip_open; the geometry fields are read-only afterwards while scroll_y/velocity evolve through the scroll API. max_scroll == max(0, canvas_h - viewport_h) is the clamp ceiling.

Invariant
0 <= scroll_y <= max_scroll after every public call.
band_count == info.tile_rows and band_h == info.tile_h.
Since
0.1.0
