Detailed Description

First-fit free-list allocator over a static pool for miniz.

Implements ra8_epub_miniz_alloc / ra8_epub_miniz_free / ra8_epub_miniz_realloc against one max_align_t-aligned static buffer. The pool is an implicit list of contiguous blocks, each prefixed by a small header carrying its payload size and a free flag. Allocation is first-fit with split; free coalesces every run of adjacent free blocks, so the pool never fragments permanently and is reusable across unbounded alloc/free cycles (miniz allocates and frees a decompressor per chapter extract).

◆ priv_alloc_const_t

enum priv_alloc_const_t : size_t

Local allocator constants.

Enumerator
k_priv_hdr_bytes 

Block-header stride, rounded up to a whole number of arena cells.

priv_cell_at indexes s_pool by off / sizeof(priv_pool_cell_t), which truncates any offset that is not a cell multiple. Keeping the header a whole number of cells means a payload that starts hdr bytes after a cell-aligned header is itself cell-aligned, so every header and payload offset divides exactly and no block is ever aliased onto a neighbour. sizeof(priv_blk_t) alone is not enough: on a target whose priv_blk_t is smaller than a cell, the bare size would leave payloads on sub-cell offsets that priv_cell_at then collapses.

k_priv_align 

Payload alignment == one arena cell.

This is >= alignof(max_align_t) (the cell embeds a max_align_t), so rounding requests up to it both satisfies the documented max_align_t guarantee and keeps every split offset cell-aligned for priv_cell_at.

k_priv_walk_max 

Upper bound on block count (NASA Rule 2 loop bound): every block is at least a header plus one alignment unit of payload.

k_priv_blk_free 

is_free value for a free block.

k_priv_blk_used 

is_free value for a used block.

◆ priv_align_up()

size_t priv_align_up ( size_t n)
static

Round n up to the payload alignment boundary.

Computes the smallest multiple of k_priv_align that is greater than or equal to n using the standard bitmask idiom: (n + mask) & ~mask where mask = k_priv_align - 1. Because k_priv_align equals sizeof(priv_pool_cell_t) (a power of two), the bitmask is exact and no division is required. The result ensures that every payload size stored in a block header is a cell-size multiple, which guarantees that priv_cell_at can index s_pool without truncation.

Parameters
[in]nRaw byte count to round up; may be zero.
Returns
Aligned byte count; always a multiple of k_priv_align and always greater than or equal to n.
Return values
0When n is 0 (zero rounds to zero).
k_priv_alignMinimum non-zero aligned size when n is in (0, k_priv_align].
Precondition
k_priv_align is a power of two and greater than zero.
n plus k_priv_align - 1 does not overflow size_t (caller is responsible; pool sizes are bounded by the pool constant).
Postcondition
Return value is a multiple of k_priv_align.
Return value is greater than or equal to n.
Note
Not thread-safe; pure computation with no shared state.

◆ priv_coalesce()

void priv_coalesce ( void )
static

Merge every run of adjacent free blocks into one.

Walks the implicit free list from the start of the pool to its end. Whenever a free block is found, its successor is examined in an inner loop: if the successor is also free its payload and header bytes are absorbed into the current block (expanding b->size by k_priv_hdr_bytes + n->size) and the check repeats with the new successor. Once the successor is either in-use or past the pool end, the outer walk advances to the next block via priv_next. Both loops are bounded by k_priv_walk_max, satisfying NASA Power of 10 Rule 2. After coalescing, no two adjacent free blocks remain in the pool, so subsequent first-fit searches see the maximum available contiguous free space.

Precondition
priv_init has been called at least once (s_init is true).
All block headers reachable from the pool base are well-formed (size is a cell multiple; is_free is 0 or 1).
Postcondition
No two adjacent blocks in the pool are both free.
The total number of payload bytes owned by free blocks is unchanged.
Returns
Nothing.
Note
Not thread-safe; must be called with exclusive access to the pool.

0.1.0

bool priv_in_pool ( const void * p)
static

True if p points inside this allocator's pool.

Compares the byte address of p against the half-open interval [priv_base(), priv_end()). Both bounds are derived from s_pool at call time, so the check remains correct after any future resize of the pool constant. The function is used by ra8_epub_miniz_free and ra8_epub_miniz_realloc to silently ignore pointers that did not originate from this allocator (e.g. a null or a foreign heap pointer), which is the behaviour expected by the miniz callback contract.

◆ priv_init()

void priv_init ( void )
static

Lay the whole pool out as a single free block (idempotent).

On the first call, writes a single priv_blk_t header at the start of s_pool whose size spans the entire arena minus the header itself and marks it free, then sets s_init to prevent re-initialisation. Subsequent calls return immediately without touching the pool, making the function safe to call at the top of every public allocator entry-point without performance cost after startup. The pool header size and free-block sentinel values are taken from priv_alloc_const_t so no magic numbers appear in this function.

Precondition
s_pool is a statically allocated array of priv_pool_cell_t with at least k_priv_hdr_bytes + k_priv_align bytes of capacity.
No concurrent call to any allocator function is in progress (single- threaded initialisation context assumed).
Postcondition
When s_init was false on entry, s_pool contains exactly one free block spanning k_ra8_epub_miniz_pool_bytes - k_priv_hdr_bytes payload bytes.
s_init is true after the call.
Returns
Nothing.
Note
Not thread-safe; must be called before any concurrent allocator use.

◆ priv_split()

void priv_split ( priv_blk_t * b,
size_t need )
static

Split b so it holds exactly need bytes, leaving a free remainder block after it.

Examines whether the block is large enough to be split: a remainder block requires at least k_priv_hdr_bytes + k_priv_align bytes beyond need. When the condition is met, a new priv_blk_t header is placed immediately after the first need aligned payload bytes of b. The remainder header's size is set to absorb all leftover bytes (b->size - need - k_priv_hdr_bytes) and is marked free. Block b is then trimmed to exactly need bytes. If the block is too small to split, it is left unchanged and the caller receives a slightly oversized allocation, which is correct because the block's original size was already at least need.

Parameters
[in,out]bBlock to split; must be a valid free block inside the pool with b->size >= need.
[in]needAligned payload size the caller requires; must be a multiple of k_priv_align and greater than zero.
Precondition
b is non-null and its header lies within s_pool.
need is a positive multiple of k_priv_align and does not exceed b->size.
Postcondition
When split occurred: b has size == need and the remainder block is marked free with size equal to the leftover payload bytes.
When no split occurred: b is unchanged.
Returns
Nothing.
Note
Not thread-safe; must be called with exclusive access to the pool.
