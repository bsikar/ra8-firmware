Detailed Description

Host tool: pack compiled .rabook files into a FAT32 SD-card image.

Builds a raw FAT32 disk image (512-byte sectors, no MBR) containing the given books, each stored under its own basename (e.g. Meditations.rabook) now that ra8_fs writes VFAT long names (#600/#633). It drives the SAME first-party ra8_fs formatter/writer the firmware reads with, so the emulator (ra8_emulator --sd image.img) and the on-device ra8_sdmmc_spi -> ra8_fs path see a byte-identical layout. The firmware still reads each book's title/author/cover from its header; the card now also carries the human-readable file name.

Usage: mkbookimg <out.img> <book1.rabook> [book2.rabook ...]

Write the whole in-memory disk out to path as a raw image.

Streams all k_img_sectors * k_block_size bytes of s_disk to path with no MBR and no padding, producing the raw 64 MiB FAT32 image the emulator attaches with --sd. A short write is treated as failure.

Parameters

Returns
0 on success, 1 if the file cannot be opened or the write is short.
Return values
0The image bytes were fully written.
1The output could not be opened, or fewer bytes than expected wrote.
Precondition
::s_disk.bytes holds a fully built image.
path is a writable path.
Postcondition
On success path holds exactly the image bytes.
The output stream is closed on every path.
Note
Not thread-safe; the tool is single-threaded.

bool dup_dest_name ( char ** argv,
int i )
static

Report whether input i's card name repeats an earlier input's.

Two sources with the same basename (from different directories) would land on the same card name and the second would replace the first (ra8_fs_write_file overwrites by name). This scans the inputs before i for a matching basename so a collision is refused rather than silently dropping a book.

Parameters
[in]argvProgram argv; the books start at argv[2].
[in]iZero-based index of the input being checked (0 .. n_books-1).
Returns
Whether an earlier input shares input i's basename.
Return values
trueSome j in [0, i) has the same basename as input i.
falseInput i's basename is unique among the inputs before it.
Precondition
argv holds valid book paths at indices [2, 2 + i].
i is a non-negative index within the input range.
Postcondition
No state is modified (pure scan over argv).
argv strings are read only, never written.
Note
Not thread-safe; the tool is single-threaded.

◆ write_books()

int write_books ( ra8_fs_mount_t * mnt,
char ** argv,
int n_books )
static

Write each input book onto the mounted card under its own basename.

For every input path in argv[2 .. 2 + n_books) derives the on-card name from the source's basename (mkbookimg_dest_name), refuses a name that collides with an earlier input (dup_dest_name), reads the whole file into memory (read_file), and writes it through ra8_fs_write_file under the human-readable long name. The first bad name, collision, read or write failure stops the run and returns non-zero.

Parameters
[in,out]mntMounted FAT32 volume to create files on.
[in]argvProgram argv; the books start at argv[2].
[in]n_booksNumber of book paths, already capped at k_max_books.
Returns
0 when every book was written, 1 on the first failure.
Return values
0All n_books files exist on the card under their basenames.
1A name was unusable/duplicate or a book could not be read/written.
Precondition
mnt is a mounted volume and argv holds n_books paths at [2..].
n_books is in 0 .. k_max_books.
Postcondition
On success n_books files exist on the card and every buffer is freed.
On failure the per-book buffer is freed before returning.
Note
Not thread-safe; the tool is single-threaded.
