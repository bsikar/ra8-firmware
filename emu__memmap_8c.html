Detailed Description

Emulated memory map implementation (see emu_memmap.h).

The region table, the host-backed TrustZone alias buffers, the TSN factory-trim seed, and the region + MMIO-window mapping – moved verbatim out of the ra8_emulator main translation unit.

◆ map_one_region()

bool map_one_region ( uc_engine * uc,
const mem_region_t * r )
static

Map one memory region into the engine.

Three physical apertures – on-chip SRAM (0x22..), OSPI XIP flash (0x80..) and external SDRAM (0x68..) – are host-backed (uc_mem_map_ptr) rather than engine-backed so their IDAU bit[28]=1 Non-secure aliases (0x32.. / 0x90.. / 0x78..) can mirror the SAME host bytes, keeping the Secure and Non-secure views coherent: SRAM lets cpu1 share IPC memory and BLXNS land on the copied NS image; OSPI lets an execute-in-place image be fetched through either view (UC_PROT_ALL includes EXEC); SDRAM lets the NS e-reader draw the framebuffer the Secure GLCDC scans back. Each physical region precedes its alias in k_regions, so its host buffer is allocated first and the alias arm reuses it at the bit[28]-stripped offset. Every other region is plainly engine-mapped. Transparent for cpu0 (uc_mem_map_ptr behaves like uc_mem_map otherwise).

◆ seed_tsn_calibration()

void seed_tsn_calibration ( uc_engine * uc)
static

Seed the on-chip temperature-sensor factory calibration into memory.

Writes the two-point trim words TSCDR / TSCDR2 (see tsn_cal_seed_t) into the mapped MRAM factory-trim page at k_tsn_cal_addr. On silicon these cells are factory-programmed; the emulator's map is blank, so without this seed ra8_tsn_convert_to_milli_c reads an unmapped address and the run bus-faults. Must be called after the memory regions (including "TRIM") are mapped.

Parameters
[in,out]ucUnicorn engine whose "TRIM" page receives the seed.
Returns
Nothing.
Precondition
The TRIM region covering k_tsn_cal_addr has been mem-mapped on uc.
Postcondition
uc holds TSCDR at k_tsn_cal_addr and TSCDR2 at the next word.
