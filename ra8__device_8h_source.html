118/* -------------------------------------------------------------------------- */
119/* Feature-presence flags */
120/* -------------------------------------------------------------------------- */
121
122/*
123 * Build-configuration flags (an explicitly-allowed macro use: they gate
124 * conditional compilation, not integer arithmetic). Prefer these semantic
125 * names over `#if defined(RA8_DEVICE_RA8P1)` in feature-guarded code so the
126 * intent ("this chip has an NPU") survives the arrival of a future part.
127 *
128 * The delta set below is the COMPLETE list of hardware differences found from
129 * primary sources; every other peripheral, base address, and memory region is
130 * identical across the two parts.
131 *
132 * NOTE (issue #224): an earlier draft of this delta set listed a "legacy
133 * ETHERC/EDMAC MAC at 0x40354000" as an RA8P1-only addition. That was a misread
134 * and is deliberately absent here. The RA8P1 Hardware User's Manual
135 * (R01UH1064EJ0130) and datasheet (R01DS0439EJ0130) contain no ETHERC block,
136 * none of the classic ETHERC/EDMAC registers (ECMR / EDMR / ...), and nothing
137 * based at 0x40354000 (that window is USBHS 0x40351000 / SCI 0x40358000 /
138 * SPI 0x4035C000). The token "EDMAC" appears only in the Buses chapter, where
139 * BOTH manuals state verbatim that "EDMAC ... means the GWCA function of ESWM"
140 * -- the descriptor-DMA bus initiator of the shared R-Switch, which the RA8D2 has
141 * too. The RA8P1's only Ethernet is the same R-Switch / ESWM subsystem as the
142 * RA8D2 (identical HUM chapters 30-36 and register bases), so there is no
143 * ETHERC feature flag. Do not re-add one without a primary-source register map.
144 *
145 * NOTE (issue #516): an earlier draft also listed "OFS3 / WDT1 option register"
146 * as RA8D2-only, behind an `RA8_HAS_OFS3` flag. That was a misread of Renesas
147 * FSP metadata and is deliberately absent here. BOTH parts have OFS3: RA8P1 HUM
148 * R01UH1064EJ0130 Ch 7.2.6 "OFS3, OFS3_SEC : Option Function Select Register 3"
149 * p 288 and Ch 7.2.7 "OFS3_SEL ... for Security" p 290 document the same word,
150 * at the same addresses and with the same WDT1 bit fields, as RA8D2 HUM
151 * R01UH1065EJ0130 Ch 7.2.6 p 287 / Ch 7.2.7 p 289. The RA8P1 likewise has the
152 * WDT1 that OFS3 configures (datasheet R01DS0439EJ0130: "Watchdog Timer (WDT)
153 * x 2"; WDT1 at 0x4020_2600). FSP's `BSP_FEATURE_BSP_HAS_OFS3` is 0 for ra8p1,
154 * which contradicts Renesas' own manual and has no consumer in open FSP source;
155 * it is not evidence. Do not re-add an OFS3 feature flag.
156 */

159#define RA8_HAS_NPU (1)
161#define RA8_HAS_NPUCLK (1)
162#else
163/* RA8_HAS_NPU / RA8_HAS_NPUCLK intentionally undefined (NPU is RA8P1-only). */
164#endif
