Detailed Description

Parsed command-line options handed to every verb.

One options struct serves all verbs (Open/Closed: a new format consumes the fields it needs and ignores the rest), passed to the descriptor entry points the way this repo passes a config struct to an *_init().

Invariant
in_path and report are non-NULL for every verb.
