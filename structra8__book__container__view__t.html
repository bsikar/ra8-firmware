Detailed Description

Parsed, bounds-checked view of a resident "RBKC" container file.

Populated by s_container_view(); every pointer aims into the caller's file buffer and every extent was verified against file_len, so the inflate loop can trust it without re-checking.

Invariant
table covers chunk_count + 1 entries; payload covers payload_len bytes; both lie within the original file buffer.
