Detailed Description

On-flash superblock at logical sector 0 (also the checkpoint commit).

Written last on any checkpoint, so a torn checkpoint leaves the prior (or dirty) superblock and forces a safe replay. All fields are 4-byte and self-packing (no padding) for a deterministic CRC.

Invariant
crc == CRC-32 over the preceding fields for a valid superblock.
