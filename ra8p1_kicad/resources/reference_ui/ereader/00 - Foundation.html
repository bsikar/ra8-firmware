01

Grayscale

16 levels, 4-bit. The only colors that exist. Four working grays do all the work; tone comes from 1-bit dither, never gradients.

The ramp · L0 → L15#000000 → #FFFFFF · step 17

Pure black (L0) and pure white (L15) carry text and paper. Everything between is structure. We commit to a deliberately small working set so screens stay high-contrast and legible on the panel.

Ordered dither gives the illusion of mid-tones using only pure black pixels — exactly how the panel shades a cover. Crisp at any zoom, no compositing. Smooth gradients are forbidden; this is the substitute.

Four flat glyph + label destinations. The current screen is marked by a fully inverted cell — no underline, no accent color. 2 px ink top edge separates it from content.

Bottom modal sheethard top edge · full repaint · no scrim
Text settings

A modal is not a translucent overlay. The lower region is repainted as a solid paper panel with a hard 2–3 px ink top edge and a short grab handle. The page behind it is the real page underneath — never dimmed, blurred, or tinted, because the panel can do none of those. Covers the lower ~60% for the text-settings sheet.
