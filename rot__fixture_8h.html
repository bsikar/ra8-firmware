Detailed Description

Baked RoT-signed image fixture (body + ra8_rot_trailer_t).

Generated by tools/rot_sign.py with the project RoT signing key (public half provisioned in libs/ra8_dfu/src/ra8_rot.c). Regenerate with: printf '...' > body.bin && \ tools/rot_sign.py sign –key ~/ra8d2-rot-signing-key.pem –image body.bin \ –out signed.bin –img-version 1 DO NOT EDIT BY HAND.
