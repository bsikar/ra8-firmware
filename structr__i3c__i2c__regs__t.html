Detailed Description

Memory-mapped register block for one IIC_B / I3C channel.

Layout matches HUM Ch 40.2 "I3C Bus Interface Register Descriptions" (p 2452-2614). All registers are 32-bit; bit fields are accessed via the k_ra8_i3c_i2c_*_pos and k_ra8_i3c_i2c_*_msk enums below.

Fields prefixed RESERVED are holes per the HUM and must not be touched.
