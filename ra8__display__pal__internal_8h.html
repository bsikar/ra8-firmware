Detailed Description

Internal vtable + handle types for the display PAL.

Tag
[Ring 4 / PAL] {World: NS}

Not part of the public API. Only the PAL dispatcher and the backend TUs include this file. Tests under tests/ MAY also include it to drive MC/DC vectors against internal helpers, but application code never should.

Defines:

  • display_backend_iface – the function-pointer table each backend fills in. Forward-declared as opaque in ra8_display_pal.h.
  • display_handle – the concrete struct that ra8_display_pal.h forward-declares as opaque. Holds the bound iface and the backend's private context pointer.
