Detailed Description

Internal per-driver state.

Single-instance driver: only one card is supported at a time. Holds the SDHI instance index plus the protocol-level state captured during init (RCA, capacity, card type). initialized gates every public API except ra8_sdcard_init / ra8_sdcard_deinit.
