Detailed Description

Static configuration passed to ra8_mipi_dsi_init.

cppcheck cannot see tests/ so it flags every field as unused; each member is read in ra8_mipi_dsi_init() in libs/ra8_hal/src/ra8_mipi_dsi.c.

Invariant
lane_count is one of k_ra8_mipi_dsi_lanes_1 or k_ra8_mipi_dsi_lanes_2 – any other value is rejected.
