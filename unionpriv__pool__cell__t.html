Detailed Description

One max_align_t-aligned storage cell of the arena.

Backing the pool with an array of this union (rather than a raw uint8_t buffer) means a pointer into the pool already carries alignof(max_align_t) – which is >= alignof(priv_blk_t). Casting such a pointer to priv_blk_t* therefore never increases the required alignment, so it is both well-defined and accepted under -Wcast-align.

Invariant
sizeof(priv_pool_cell_t) == alignof(max_align_t).
