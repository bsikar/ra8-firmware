Detailed Description

RBKC (.rabook) container inspector for ra8_fmt.

The RBKC container has a fixed header, a strictly increasing count + 1 offset table, then that many concatenated zlib streams. Dumping the chunk inventory with each entry's byte range is exactly what reveals a malformed book: a non-monotonic table, a final offset that disagrees with the payload length, or an entry whose window runs past the file are all silent at open time but fatal at read time.

"One unit" for this container is one whole compiled book – it is not built from a single image, so it declares no convert verb; the compilers under tools/epub_compile remain the producers. See the report note in ra8_fmt_registry.c.

Check the two RBKC header words: reserved and count.

The RBKC header carries a reserved word that must read zero and a chunk count that must be non-zero. A non-zero reserved word is an anomaly the caller still reports around – the rest of the container is readable – whereas a zero count makes every derived table offset meaningless, so the walk cannot continue.

Parameters
[in]outReport stream.
[in]reservedReserved header word, expected zero.
[in]countChunk or page count, expected non-zero.
[in]count_nameField name to use in the anomaly line.
[in,out]verdictDowngraded to a validation failure on any anomaly.
Returns
Whether the container is coherent enough to keep inspecting.
Return values
truecount is non-zero; the table walk can proceed.
falsecount is zero; verdict is already a failure.
Precondition
out, count_name and verdict are non-null.
verdict holds the verdict so far.
Postcondition
Any anomaly has been reported to out.
verdict is never upgraded, only downgraded.
Note
Not thread-safe.

Walk a count + 1 uint64 offset table, printing and validating it.

Enforces the invariants the RBKC offset table must hold: offset[0] == 0, the table is strictly increasing, and offset[count] equals the remaining payload length. Each entry's byte range is printed so a malformed inventory is visible, not merely reported.

Parameters
[in]srcContainer bytes (non-NULL).
[in]table_offByte offset of offset[0] within the container.
[in]countEntry count (the table holds count + 1 offsets).
[in]payloadByte offset where the concatenated streams begin.
[in]optsOptions carrying the report sink and verbosity.
Returns
Result code.
Return values
k_ra8_okTable is well-formed.
k_ra8_err_validation_failedA bound, ordering or length check failed.
Precondition
src holds the whole container.
count is the header-declared entry count.
Postcondition
Every anomaly found was written to the report sink.
No state other than the stream is mutated.
Note
Not thread-safe (writes one stream).
