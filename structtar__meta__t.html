Detailed Description

Overrides accumulated over one member's pax / GNU meta prelude.

Reset at the start of every ra8_unarch_tar_next; the real header consumes whatever the prelude established (pax path / size, GNU longname).

Invariant
name_len <= name_cap after every update.
See also
ra8_unarch_tar_next()
