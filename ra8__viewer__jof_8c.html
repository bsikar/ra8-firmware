Detailed Description

JOF long-strip reader engine: vertical-scroll tile atlas rendering.

Drives ra8_longstrip over an ra8_tile_cache for the firmware-native .jof tile atlas the downloader writes with ra8_jof_produce. The whole atlas is slurped into memory and read back through a memstore pread, so the engine sees exactly the demand-paged interface it uses on the board; DEFLATE bands are decoded on cache miss into a fixed pool of LRU cells.

The tall canvas is paginated into viewport-height windows. Each viewer "page" scrolls the strip by one viewport and composites the visible bands through a viewer-owned blit that converts whatever the strip's native bit depth is (gray / RGB565 / RGB / RGBA) into the RGB565 target.

◆ viewer_jof_seek()

ra8_err_t viewer_jof_seek ( viewer_jof_t * w,
uint32_t page )
static

Scroll the strip so that page page sits at the top of the viewport.

The strip's scroll clamp is derived from its viewport height, so a paginated caller must first tell the engine how tall the page it is about to draw actually is. The final page of a strip whose height is not a whole multiple of the page height is SHORT; leaving the engine at the full page height would clamp this seek backwards to canvas_h - page_height and re-composite a window the previous page already showed – visible as duplicated content with a seam. Setting the viewport to the page's real content height makes the requested position land exactly on the recomputed clamp.

Parameters
[in,out]wJOF state of an open strip (non-NULL).
[in]pageVertical page index.
Returns
ra8_err_t from ra8_longstrip_set_viewport / ra8_longstrip_scroll_by.
Return values
k_ra8_okThe strip is positioned at page page.
k_ra8_err_out_of_rangepage lies past the end of the strip.
Precondition
w is an open JOF strip.
page is a candidate page index down the strip.
Postcondition
On k_ra8_ok the viewport top sits at page page's content.
The viewport height is set to the page's real (possibly short) height.
Note
Not thread-safe (mutates the strip's scroll state).
