Detailed Description

Import-time transcode knobs: tile geometry, budget caps, work arena and the destination store.

Mirrors the producer configuration (ra8_jof_produce.h) minus the source, which the import path streams from the archive entry itself. Size work with ra8_jof_work_bytes() over the same caps. webp_work is the optional whole-frame arena for WebP manifest images (size it with ra8_jof_webp_work_bytes()); leave it NULL to fail-closed reject WebP entries the way JPEG/PNG-only importers always did.

Invariant
tile_w/tile_h non-zero; work covers work_cap.
webp_work is NULL, or it covers webp_work_cap.

ra8_epub_tile_binder_import()
