Detailed Description

A preserved CSS stylesheet and the chapter it scopes to.

source_off points at the verbatim stylesheet text so the CSS cascade engine receives the real rules. scope_chapter is a chapter index, or k_ra8_book_nil for a book-wide stylesheet.
