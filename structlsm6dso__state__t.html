Detailed Description

One ST LSM6DSO IMU device: a flat auto-incrementing register file.

reg_ptr is set by the first byte of each write phase (the start register) and advances one per byte for both writes (config) and reads (burst). A read served past the file end returns 0. ptr_set is cleared at STOP so the next transaction's first write byte is taken as a fresh register pointer.
