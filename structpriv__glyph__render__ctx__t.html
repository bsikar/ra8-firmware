Detailed Description

Per-glyph state handed to the glyph-atlas render-on-miss callback.

The ::ra8_glyph_atlas render seam is fixed at bind time, but the font, scale, and bitmap extent for the glyph currently being drawn vary per call. The blit path computes the box once (priv_blit_glyph) and stashes them here immediately before ra8_glyph_atlas_get, so a cache miss rasterises the right glyph at the known size without recomputing the box. Single instance (render is single-threaded, like s_glyph_mask and s_faces).

Invariant
When a miss can fire, font is non-NULL and w, h are the positive extents the blit path already validated for the glyph.
