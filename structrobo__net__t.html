Detailed Description

Fake mdl_net_iface_t backend: serves one robots.txt, records the UA.

The ctx behind a fake vtable. Every fetch the session issues is a /robots.txt GET; this records the URL and the transmitted User-Agent so a test can assert exactly what reached the wire.

Invariant
calls counts every dispatched fetch.
