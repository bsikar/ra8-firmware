Detailed Description

Internal vtable type for the ra8_io byte-stream facade.

Tag
[Ring 4 / PAL] {World: NS}

Not part of the public API. Only the stream dispatcher and the sink translation units include this file. Tests under tests/ MAY include it to drive MC/DC vectors against internal helpers; application code never should.

Defines ra8_io_stream_iface – the function-pointer table each sink fills in and binds into a caller-owned ra8_io_stream_t. It is forward declared opaque in ra8_io_stream.h.
