Detailed Description

One laid-out <img> rectangle (decoded + blitted at render time).

Produced by the layout pass when an image loader + decode arena are bound (see ra8_reflow_set_image_loader()). Coordinates are page-local – the same space as ra8_reflow_glyph_t – so render offsets them by the page origin. The src_off / src_len slice indexes the engine text pool and is handed back to the loader at render time to re-fetch the encoded bytes (the decoded pixels are never stored – decode is on-demand per page flip).
