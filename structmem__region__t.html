Detailed Description

One emulated memory region: name, base address, and byte size.

A row of the RA8D2 memory-map table. Alias rows share a host backing with their physical row (the backing row precedes its alias in the table, so the buffer exists before the alias maps onto it).

Invariant
Regions do not overlap; alias rows follow their backing row.
See also
emu_memmap_regions() Returns the table.
