Detailed Description

Recording virtual clock: now advances only when the governor sleeps.

now_ms is what mdl_now_fn returns; each injected sleep both advances now_ms (so the token bucket refills across calls) and records the requested duration, so timing is asserted without any wall-clock time elapsing.
