Detailed Description

ra8_fmt command-line entry: parse the verb + options, then dispatch.

Three verbs over the ra8_fmt_desc_t registry:

ra8_fmt convert --format jof --in page.jpg --out page.jof
ra8_fmt inspect page.jof [--verbose]
ra8_fmt verify --format jof --in page.jpg [--out recon.ppm]

inspect auto-detects the format from the container magic, so --format is only required where the input is a source file rather than a container (convert, verify).
