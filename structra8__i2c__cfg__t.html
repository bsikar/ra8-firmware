Detailed Description

Configuration descriptor for ra8_i2c_init.

The RIIC internal reference clock is IICphi = PCLKB / 2^CKS per HUM Ch 39.2.3 "ICMR1" p 2374, so the bit-rate divider needs the current PCLKB frequency. cppcheck cannot see tests/ so it flags every field as unused; both members are read in ra8_i2c_init.

Invariant
bus_hz is non-zero and pclkb_hz is non-zero.
