71/* Armv7E-M / Armv8-M exception model constants (the part Unicorn's Cortex-M33
72 * core leaves to software here -- it has no NVIC/exception unit). EXC_RETURN
73 * magic values steer the unstack: bit2 picks the return stack (1 = PSP, 0 =
74 * MSP), bit3 the return mode (1 = Thread, 0 = Handler), bit4 the frame type
75 * (1 = basic 8-word frame, 0 = FP extended frame). On Armv8-M the value also
76 * carries bit6 = S (1 = return to Secure, 0 = Non-Secure) and bit5 = DCRS, so a
77 * Non-Secure thread return is 0xFFFFFFBC -- NOT one of the Armv7-M 0xFFFFFFF_
78 * values. is_exc_return() therefore matches the whole bits[31:7]-set EXC_RETURN
79 * prefix (0xFFFFFF80..FF), and exc_enter/exc_return branch on bit4 (FType) to
80 * stack/unstack the S0-S15 + FPSCR words whenever an FP extended frame is in
81 * play (ThreadX's PendSV mirrors this with its own TST LR,#0x10 on S16-S31). */
