Detailed Description

Opaque handle to one open document and its owned rasterisation buffers.

One open document: file backing, engine state, and owned buffers.

Allocated by ra8_viewer_open, released by ra8_viewer_close. The full definition lives in ra8_viewer_reader.c so callers depend only on the API below.

Since
0.1.0
Invariant
fb always owns k_ra8_viewer_fb_width * k_ra8_viewer_fb_height RGB565 pixels once ra8_viewer_open has returned k_ra8_ok.
rt565 points at fb except while a scroll tile is rendering.
Since
0.1.0
