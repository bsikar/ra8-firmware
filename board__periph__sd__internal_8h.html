Detailed Description

Module-private FAT formatter shared by the board_periph_sd TUs.

Carries what the three board_periph_sd translation units share: the modelled card's state type and the single instance of it, the SD SPI sizing constants that type is built from, and the blank-card (–sd-new) FAT16/FAT32 in-memory formatters. board_periph_sd.c models the SPI protocol, board_periph_sd_image.c owns the backing-image lifecycle, and board_periph_sd_format.c does the pure image-buffer FAT transforms.

uint32_t sd_format_fat16 ( uint8_t * img,
uint32_t total_sectors,
const char * label )

Format img as a FAT16 volume of total_sectors.

Writes a complete BPB (boot frame, geometry, label, volume id), the signature bytes and the FAT[0]/FAT[1] reserved entries – enough to satisfy a host fsck_msdos and the firmware's ra8_fs mount alike.

Parameters
[out]imgZeroed card image buffer.
[in]total_sectorsCard capacity in 512-byte sectors.
[in]labelVolume label (space-padded to 11 chars).
Returns
Sectors per cluster the formatter selected.
Return values
0Never (a positive cluster size is always chosen).
Precondition
img holds at least total_sectors * 512 zeroed bytes.
total_sectors fits FAT16 cluster limits (caller picked FAT16).
Postcondition
The image mounts as an empty FAT16 volume.
Note
Pure buffer transform; thread-safe on distinct buffers.
Since
0.1.0
