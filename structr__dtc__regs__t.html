Detailed Description

DTC controller register block at 0x4000AC00.

Layout verified against FSP R_DTC_Type (R7KA8D2KF_core0.h lines 6581-6732). Total size = 0x30 bytes. Reserved members are named with an underscore prefix to keep the FSP register names directly addressable.
