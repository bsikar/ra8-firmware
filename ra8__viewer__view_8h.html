Detailed Description

Plain-C ABI for the viewer's desktop reader window (Cocoa on macOS).

The window is a native NSScrollView that reads the document as a continuous vertical strip: it pulls tiles from the reader (ra8_viewer_tile_count / ra8_viewer_render_tile565), scales each to the window width, and stacks them so the whole series scrolls smoothly and endlessly with the trackpad, wheel, scrollbar, or Page/Home/End keys. Tiles are rendered lazily as they scroll into view and dropped when far away, so a long chapter stays within a bounded memory budget. Resizing the window re-fits every tile to the new width.

The window runs cooperatively: ra8_viewer_view_pump drains pending events from the caller's loop rather than taking over with [NSApp run]. The implementation is Objective-C (ra8_viewer_view.m); this header stays pure C so the C reader and main need no Objective-C.

Open a resizable, fit-to-width scrolling reader window over reader.

Creates a native scrolling window that reads the document as one continuous vertical strip, pulling and scaling tiles lazily as they scroll into view. The view borrows reader and renders on demand; a headless host with no display returns NULL.

Parameters
[in]readerOpen reader whose tiles the window renders (non-NULL).
[in]titleWindow title (NUL-terminated, may be NULL).
Returns
New view handle, or NULL if a window could not be created (e.g. a headless host with no display).
Return values
NULLNo window could be created on this host.
Precondition
reader is an open document that outlives the view.
A window system is available.
Postcondition
On success a window is open and borrows reader.
On failure no window or view is created.
Note
The view borrows reader; the reader must outlive the view. Not thread-safe; call on the main thread.

bool ra8_viewer_view_pump ( ra8_viewer_view_t * view)

Drain pending window events cooperatively.

Processes the events queued since the last call and returns without blocking, so the caller keeps its own run loop rather than handing control to the platform's blocking run call. Returns true once the user has closed the window.

Parameters
[in]viewView handle (NULL treated as closed).
Returns
true when the window has been closed (the caller should exit).

falseThe window is still open; keep pumping.

Called from the thread that created the view.
Postcondition
Events queued before the call have been processed.
The view is unchanged except for consumed events.
