Detailed Description

One external-IRQ-pin configuration descriptor.

Populate one of these and hand it to ra8_icu_configure_irq_pin(). Fields map directly onto IRQCRi bit fields per HUM Ch 14.2.12 (p 535).

cppcheck cannot see tests/ so it flags every field as unused; each member is read in ra8_icu_configure_irq_pin in libs/ra8_hal/src/ra8_icu.c.
