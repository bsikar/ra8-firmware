Detailed Description

Shared file I/O, byte-field readers and the hex dumper for ra8_fmt.

Format-agnostic plumbing every descriptor leans on: slurp a file into an owned blob, write one back out, read the little-endian scalar fields the first-party containers store their headers in, and render a labelled hex + ASCII window – the byte-level evidence that makes inspect a debugging instrument rather than a pretty-printer.
