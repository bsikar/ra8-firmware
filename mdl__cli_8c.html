◆ mdl_cli_parse_nums()

bool mdl_cli_parse_nums ( const mdl_args_t * a,
mdl_nums_t * n )

Strictly parse and validate every numeric CLI field.

Converts the string-form numeric options (--timeout, --chapters, --max, --seed, --from, and --max-bytes for presence-validation) into typed scalars, rejecting any non-numeric or trailing-garbage value with a usage message on stderr rather than silently substituting 0. --chapters of 0 is clamped up to 1.

Parameters
[in]aParsed command-line options (never NULL).
[out]nReceives the validated scalars (never NULL).
Returns
Whether every present numeric field parsed cleanly.
Return values
trueAll fields valid; n is fully populated.
falseA field was non-numeric or out of range; a usage error was printed and n is partially written.
Precondition
a and n are non-NULL; a was populated by mdl_cli_parse.
The caller aborts with a usage exit code when this returns false.
Postcondition
On true, n->chapters >= 1 and every scalar reflects the args.
On false, a diagnostic naming the bad option was written to stderr.
Note
Not thread-safe: writes caller storage and stderr.
Since
0.1.0
