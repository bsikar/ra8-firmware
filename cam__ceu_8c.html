Detailed Description

CEU parallel (DVP) capture: DVP pin routing, open, arm/poll, buffer.

Tag
[Ring 6 / APP] {World: S}

Implements the Capture Engine Unit half of the camera self-test declared in cam_ceu.h. Owns the 11-entry DVP pin map, the QVGA YUV422 open-time descriptor, the 8-byte-aligned single-frame capture buffer, and the arm + bounded-poll capture wrapper. The raw ra8_ceu_* driver is wrapped so the app never touches the ra8_ceu_config_t descriptor.

◆ cam_capture_one()

ra8_err_t cam_capture_one ( void )

Capture one CEU frame into the module buffer, polling CETCR.CPE.

Arms the capture engine at the internal frame buffer and spins a bounded poll on the CEU status register until the one-frame-end (CPE) event latches, then clears it.

Returns
ra8_err_t; ok when the CEU reports one-frame-end.
Return values
k_ra8_okFrame captured into the module buffer.
k_ra8_err_hw_timeoutNo CPE within the bounded wait.
Precondition
cam_ceu_setup completed and the sensor is streaming.
The CEU DVP pins are routed.
Postcondition
The module frame buffer holds one frame of DVP bytes on success.
The capture engine is idle (CE cleared).
Note
Thread safety: not thread-safe.

0.1.0

Returns the module-owned frame buffer that cam_capture_one fills. The buffer is k_cam_frame_bytes long and 8-byte aligned for the CEU destination-address register.

ra8_err_t cam_ceu_setup ( void )

Fill the CEU descriptor and open the capture engine for a QVGA grab.

Populates the open-time descriptor for a single-shot data-synchronous 8-bit QVGA YUV422 capture and hands it to ra8_ceu_init. Wraps the fill-then-init pair so callers never touch the raw CEU descriptor type.

Returns
ra8_err_t; ok when the CEU is initialized and idle.
Return values
k_ra8_okCEU configured and ready to arm.
k_ra8_err_invalid_argThe descriptor was rejected by ra8_ceu_init.
k_ra8_err_null_ptrInternal descriptor pointer was NULL (cannot occur).
Precondition
The CEU DVP pins are routed (cam_route_ceu_pins).
The sensor is streaming a QVGA YUV422 frame.
Postcondition
The CEU holds the QVGA descriptor and is ready for cam_capture_one.
No frame has been captured yet.
Note
Thread safety: init context only.

ra8_err_t cam_route_ceu_pins ( void )

Route the 11 J35 parallel-camera data/sync pins to the CEU.

Muxes VIO_D[7:0], VIO_VD, VIO_HD and VIO_CLK from GPIO to the CEU peripheral function so the capture engine sees the DVP bus.

Returns
ra8_err_t; first failing route or ok.
Return values
k_ra8_okAll pins routed to the CEU peripheral.
k_ra8_err_gpio_conflictA pin was already claimed.
Precondition
ra8_pfs_init context (IOPORT reachable).
DIP SW4-6 is ON (board in parallel-camera mode).
Postcondition
All 11 pins carry the CEU (VIO_*) function (PMR=1, PSEL=CEU).
No CEU pin is left as GPIO.
Note
Thread safety: init context only.
