Detailed Description

Descriptor for one transcoded image in the image pool.

id_off is the original manifest href so an <img src> attribute value resolves to this entry. Raster images are packed grayscale at source resolution (panel-ready, no decode; an opt-in compile knob can clamp the long edge) – 4bpp (2px/byte) or 8bpp (1px/byte) per pixel_format; SVG is kept as verbatim vector source. Pool bytes are raw – the blob is chunk-DEFLATE-wrapped on disk (see ra8_book_container_t) and inflated on open, so per-image compression would not help – thus data_size == raw_size and data_off indexes the image pool.
