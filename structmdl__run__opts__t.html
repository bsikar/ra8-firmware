Detailed Description

Cross-cutting options threaded into every run mode.

Bundles the network policy and identity/politeness knobs so the run entry points take one options pointer rather than a long, swappable scalar parameter list.

Invariant
policy.max_response_bytes is non-zero for a bounded fetch.
