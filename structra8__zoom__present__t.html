Detailed Description

What the reader must flush, and with which waveform.

Produced by ra8_zoom_view_present and consumed by the reader's display call. present is false when nothing changed since the last present, which is the common case in a polling main loop and is what keeps an idle reader from refreshing an e-ink panel forever.

Invariant
When present is false, rect and refresh are unspecified.
rect always equals the view's destination rectangle: a pan moves every pixel in the viewport, so there is no smaller true dirty region.
Example:
ra8_zoom_present_t plan = {};
if ((ra8_zoom_view_present(&view, &plan) == k_ra8_ok) && plan.present) {
const display_rect_t r = { .x = (uint16_t)plan.rect.x, .y = (uint16_t)plan.rect.y,
.w = (uint16_t)plan.rect.w, .h = (uint16_t)plan.rect.h };
(void)display_flush(d, r, (plan.refresh == k_ra8_zoom_refresh_fast)
? k_display_refresh_fast : k_display_refresh_quality);
}
