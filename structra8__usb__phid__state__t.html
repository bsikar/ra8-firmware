Detailed Description

Singleton shadow state for the device-HID function.

Tracks descriptor pointers, endpoint numbers, idle rate (set by SET_IDLE), protocol (boot vs report, set by SET_PROTOCOL), and the application's class-setup callback. The device-side state machine is intentionally request-driven; there is no enumeration step counter (the host drives that).
