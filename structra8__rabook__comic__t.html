Detailed Description

Mutable state for one image-sequence-to-RABOOK build.

Initialize with ra8_rabook_comic_init and treat every field as private until ra8_rabook_comic_finish returns.

Invariant
page_count == builder.chapter_count == builder.image_count.
active is false after the first terminal failure or finish.

0.1.0
