Detailed Description

One decoded MVE contiguous load/store.

Filled by mve_mem_decode and consumed by mve_mem_exec. The addressing mode is always pre-indexed, so the accessed address is Rn +/- off and write-back stores that same address into Rn.

Invariant
qd is in [0, 7] – it comes from a 3-bit field.
rn is in [0, 15] – it comes from a 4-bit field and may name SP.
