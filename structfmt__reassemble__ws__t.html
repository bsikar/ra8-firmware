Detailed Description

Everything one reassembly pass needs: the reader, the sizes, the buffers.

The three buffers are not independent – each is sized from the same parsed geometry, and none is useful without the others – so they travel with the sizes that produced them rather than as six loose arguments. Grouping them also makes the ownership split visible: cell and scratch die with the pass, while px is what the caller walks away with.

Invariant
After a successful priv_open_reassemble_ws all three pointers are non-NULL; after a failed one all three are NULL.
raster equals stride times the atlas height.
Example:
fmt_reassemble_ws_t ws = {};
if (priv_open_reassemble_ws(atlas, info, &ws)) {
// ... use ws.px ...
free(ws.cell);
free(ws.scratch);
}
