# Arm Ethos-U Vela -- offline TFLite -> Ethos-U command-stream compiler.
#
# HOST BUILD TOOL ONLY. Vela runs on the developer/CI host at build time to
# compile a .tflite model into an Ethos-U55-optimized .tflite (the operators the
# NPU can run are replaced by an "ethos-u" custom op wrapping a Vela command
# stream). NOTHING from this package is linked into firmware; the on-device
# runtime is the vendored TFLite-micro under libs/third_party/tflite-micro.
#
# Pinned for reproducible command-stream output. See docs/SOUP/vela.md and
# tools/vela/README.md. License: Apache-2.0.
#
# Install into a throwaway venv:
#   python3 -m venv .venv-vela && . .venv-vela/bin/activate
#   pip install -r tools/vela/requirements.txt
ethos-u-vela==5.1.0
