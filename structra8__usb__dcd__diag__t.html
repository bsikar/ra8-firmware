Detailed Description

Externally-readable diagnostic counters for OUT-pipe stall debug.

Read these via JLink to localise where bulk-OUT data flow stops. Layout in declaration order, 4 bytes each. Address resolved via arm-none-eabi-nm | grep g_diag. Increment-only; never cleared at runtime so a JLink dump after a single host write tells the full story.
