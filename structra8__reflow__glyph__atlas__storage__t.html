Detailed Description

Caller-owned backing storage for the render-path glyph cache (#164).

Mirrors ra8_glyph_atlas_cfg_t minus the render seam: ra8_reflow supplies its own stb_truetype rasteriser as the render-on-miss callback, so the caller provides only the fixed storage. All arrays are caller-owned (typically static in the ereader app, carved from a tier arena) and must out-live the engine. meta, keys, and dims are parallel per-cell arrays (cell_count entries each); cell_mem holds the packed alpha-8 glyph bitmaps. A glyph whose bitmap exceeds cell_bytes is not cached – the render path falls back to direct rasterisation for it, so output is unchanged.

Invariant
cell_bytes, cell_count, and bucket_count are all non-zero.
