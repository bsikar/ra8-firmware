Detailed Description

One DOM node.

Children form a singly-linked sibling chain.

Walk an element's children by reading first_child then following each node's next_sibling until k_ra8_book_nil. Element nodes set name_off (tag name) and may have attributes; text nodes set text_off and have neither attributes nor children.

Invariant
kind == k_ra8_book_node_text implies attr_count == 0, first_attr == nil and first_child == nil.
