Detailed Description

A device on the modelled I2C bus: 7-bit address + read/write callbacks.

The write callback receives each byte the controller transmits after the address (register pointer, then payload). The read callback fills buf with up to max response bytes for the device's current state and returns the count; the bus model serves them to the controller one ICDRR read at a time. present false means no device answers that address (the bus NACKs).
