◆ mdl_pack_combined()

size_t mdl_pack_combined ( mdl_format_t format,
bool allow_incomplete,
const char * series_dir,
const char * combined_rel,
const mdl_fetch_stats_t * stats )

Package a combined page folder, refusing an incomplete archive by default.

A combined archive assembled from a run that lost a chapter or a page would look complete while silently missing pages, so it is packaged only when the run is clean (per mdl_fetch_run_incomplete) or when allow_incomplete is set – in which case the archive is named .INCOMPLETE so its partial state is visible without opening it. Nothing is packaged when no chapter completed.

Parameters
[in]formatOutput container/format.
[in]allow_incompletePackage (and mark) even when the run is incomplete.
[in]series_dirAbsolute, resolved series directory.
[in]combined_relCombined page folder leaf (relative to series_dir).
[in]statsThe finished run's tallies (never NULL).
Returns
The number of export failures (0 when packaged, skipped, or clean).
Return values
0UPackaged, or deliberately not packaged (nothing lost, or refused).
1UA path was rejected or the export itself failed.
Precondition
series_dir, combined_rel, stats are non-NULL.
stats was produced by mdl_fetch_run for this combined_rel.
Postcondition
An incomplete run is not packaged unless allow_incomplete is set.
A forced incomplete archive is named .INCOMPLETE.
Note
Not thread-safe (shared cwd during path resolution).
See also
mdl_fetch_run_incomplete

◆ mdl_pack_one()

size_t mdl_pack_one ( mdl_format_t format,
const char * series_dir,
const char * chap_id )

Package one downloaded chapter folder into format.

Composes <series_dir>/<chap_id> as the source page folder and writes the container beside it (or, for a directory-output format such as JOF, per-page siblings inside the folder). A path that would escape the series directory, or an export error, is reported and counted as one failure.

Parameters
[in]formatOutput container/format (never k_mdl_fmt_loose here).
[in]series_dirAbsolute, resolved series directory.
[in]chap_idSanitised chapter identifier (the page folder leaf).
Returns
The number of export failures (0 on success, 1 on any failure).
Return values
0UThe chapter was packaged.
1UA path was rejected or the export failed (diagnostic printed).
Precondition
series_dir and chap_id are non-NULL and NUL-terminated.
series_dir names an existing directory.
Postcondition
On success a container (or JOF siblings) exists for the chapter.
On failure a diagnostic naming the chapter was written to stderr.
Note
Not thread-safe (shared cwd during path resolution).

0.1.0
