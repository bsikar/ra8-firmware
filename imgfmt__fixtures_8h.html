Detailed Description

Baked BMP + GIF test images for the ereader_imgfmt gate.

The two stb_image formats (STBI_ONLY_BMP / STBI_ONLY_GIF) that had no example. Each is a 40x30 four-quadrant image, byte-identical run to run. Generated by make_imgfmt_fixtures.py. Pure ASCII, 16 bytes per row.
