Detailed Description

HAL-based LED-blink demo for EK-RA8D2 (using ra8_board_ek_ra8d2).

Tag
[Ring 6 / APP] {World: S}

Drives all three EK-RA8D2 user LEDs at a 1 Hz square wave using the board-support layer (libs/ra8_board_ek_ra8d2). Compared to the earlier raw-pin variant in examples/blink/main.c this demo doesn't reach into ra8_port_constants.h for the LED pin numbers directly; it speaks in board coordinates ("LED1, LED2, LED3") and lets the BSP look up the right RA8D2 pins per UM Table 24 p 31.

Sequence:

  1. ra8_time_init() – 1 ms SysTick on the reset-default MOCO.
  2. ra8_board_led_init(led) for each LED (P600 / P303 / PA07).
  3. ra8_isr_globals_enable() to let SysTick_Handler run.
  4. Loop: ra8_board_led_toggle(led) for each LED, then sleep.

◆ g_blink_hal_tick

volatile uint32_t g_blink_hal_tick = 0U

HIL liveness counter – incremented each main-loop iteration.

Read externally by scripts/hil/jlink_memprobe.sh via SWD; the script halts the chip, samples this value, lets the chip run for N seconds, halts again, and asserts the delta >= HIL_PROBE_MIN_ADVANCE. Catches the "PC is in MRAM but main loop never iterated" failure mode that the plain HIL_MODE=alive check misses.

volatile keeps the increment alive under optimization; the global (non-static) keeps the symbol linker-visible without –gc-sections culling.

Note
Read externally by J-Link only; firmware never reads back.
