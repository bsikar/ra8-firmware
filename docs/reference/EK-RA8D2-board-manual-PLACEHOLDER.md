# EK-RA8D2 board manual -- audit placeholder

The Renesas EK-RA8D2 v1 board manual has not yet been committed to
`docs/reference/`. Until it lands, every example app that picks pin
mux values has to guess against the chip-side datasheet
(`r01ds0493ej0150-ra8d2.pdf`) plus the FSP `board/ra8d2_ek/board.c`
reference file. Those guesses are tagged in the source with a
`/* TODO: confirm against EK-RA8D2 v1 board manual ... */` marker so
they show up in `grep`. This document is the auditable index of
those markers, generated by hand at Wave 11 / Sweep 15 / Phase 6.

When the real board manual is committed:

1. Replace this file with a real `EK-RA8D2-board-manual.md` that
   summarises the connector / pin tables.
2. For each row below, walk to the cited file:line, confirm the
   pin against the manual table, and either delete the `TODO:
   confirm` comment or update the cited PSEL value. Commit each
   confirmation as a small focused change so reviewers can follow.

## Reference material until the manual lands

- Chip datasheet `docs/reference/r01ds0493ej0150-ra8d2.pdf`
  ("Pin Functions" section) -- authoritative for what a pin **can**
  be muxed to, but not what it is **wired** to on the EK board.
- Renesas FSP source tree `board/ra8d2_ek/board.c` (read-only
  external reference) -- pin tables that match the EK-RA8D2 schematic
  snapshot Renesas ships in the FSP package.
- Renesas part page <https://www.renesas.com/en/products/ra8d2> -- the
  PDF "Quick Connect Guide" linked from the EK-RA8D2 page mirrors the
  paper insert that ships with the kit.
