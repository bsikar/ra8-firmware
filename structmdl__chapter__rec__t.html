Detailed Description

One chapter's coverage in library state.

Keyed by chapter_id (a parsed, sanitised identifier), NOT by position in a scraped list, so it stays valid as the site changes.

Invariant
pages_done <= page_count once page_count is known (> 0).
complete is true only after every page was fetched and verified.
