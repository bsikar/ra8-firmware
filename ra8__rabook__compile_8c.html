Detailed Description

RABOOK1 emitter implementation (see ra8_rabook_compile.h).

Zero-heap builder back-end of the #149 on-device EPUB -> .rabook compiler. Each builder call appends into a caller-provided arena; ra8_rabook_finalize lays the tables and pools out at the contract offsets, fills the 100-byte header, and CRC-32s the body so the blob passes ra8_book_validate. The table order, field packing and CRC variant mirror tools/epub_compile/epub_compile.py for byte compatibility. Records are the pinned, padding-free structs from ra8_book.h; the target and the host test are both little-endian, so a copy of those structs IS the wire layout.

◆ rabook_crc32()

uint32_t rabook_crc32 ( const uint8_t * data,
uint32_t len )
static

Compute a CRC-32/ISO-HDLC over a byte range (bitwise, no table).

Seeds with k_rabook_crc_init, folds eight bits per byte with the reflected k_rabook_crc_poly, and XORs the seed back out – the exact variant ra8_book_validate expects (check value 0xCBF43926 over "123456789"), so the emitted CRC verifies bit-for-bit on device.
