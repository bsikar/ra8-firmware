Detailed Description

Header prefixing every pool block.

Two size_t fields keep the header a multiple of max_align_t on both the 32-bit target and the 64-bit host, so the payload that follows is naturally aligned when the pool base is.

Invariant
size is a multiple of alignof(max_align_t).
is_free is 0 (in use) or 1 (free).
