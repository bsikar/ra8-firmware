Detailed Description

One decoded RAR block: a file member, a directory, or a skipped block.

Filled by ra8_rar_next. next_off always advances strictly past the current block, so a caller can walk the archive with a bounded loop. For a file member (is_file == 1) the data area is [data_off, data_off + pack_size); a STORE member (method == k_ra8_rar_method_store) has pack_size == unp_size literal bytes.

Invariant
next_off > <block offset> for every well-formed block.
is_file == 0 implies the name buffer is left empty.
