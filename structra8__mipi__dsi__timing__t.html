Detailed Description

LP / HS guard-band timing values.

One-to-one mapping with mipi_dsi_timing_t from the FSP – carries the values that ultimately land in CLSTPTSETR and LPTRNSTSETR.

cppcheck cannot see the test TU so it flags every member as unused; each value is consumed by ra8_mipi_dsi_init() in libs/ra8_hal/src/ra8_mipi_dsi.c.
